## 🚀 Featured Projects

### 🚗 AI-Powered Smart Vehicle Advisor

**Full Stack AI application | Next.js · React · TypeScript · PostgreSQL · Supabase · Gemini**

An intelligent Hebrew-language conversational system that helps employees compare vehicle options and understand their estimated net salary impact.

**Key features:**
- AI-powered understanding of natural-language requests
- Conversion of user requests into structured, validated JSON actions
- Zod schema validation and controlled server-side execution
- Deterministic financial calculations based on structured data
- Role-based authentication and PostgreSQL Row-Level Security
- Persistent conversation history
- LLM provider fallback and error handling
- Automated tests with Vitest

**Architecture:** AI interprets user intent, while validated application logic performs database operations and calculations.
