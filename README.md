## 🚀 Featured Projects

### 🚗 [AI-Powered Vehicle Advisor](https://github.com/RacheliWasserman/strauss-carwise)
A Hebrew conversational web application that helps users explore vehicle options and understand their estimated net salary impact.

- Built with **Next.js, React, TypeScript, PostgreSQL, and Supabase**.
- Uses an **LLM to interpret natural-language requests into structured actions**, with validation before execution.
- Keeps financial calculations **deterministic and separate from AI-generated interpretations**.
- Includes role-based access controls, row-level security, and automated tests.
